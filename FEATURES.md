# Features of SyncMyPod

- [x] Support iPod 5G, 5.5G, 6G, 6.5G/7G
- [x] Support iPod nano 7G
- [x] Sync M4A/AAC, M4A/ALAC, MP3, FLAC, WAV, AIFF files (the latter three are excluded from iPod)
- [x] Sync entire library
- [x] Sync partial library (select artist/album)
- [x] Create playlists
- [x] Sync playlists
- [x] Drag to reorder playlists in sidebar
- [x] Append track artist to title
- [x] Detect meta-data/artwork changes
- [ ] Backup/restore database
- [x] Sync by genre
- [x] Choose all, selected or none separately for songs, playlists, podcasts and audiobooks
- [x] Multithreaded library scan
- [x] Light/dark mode
- [x] Tag editor
- [x] Help system
- [x] Eject button
- [x] iTunes-style sorting (ignore "A", "An", and "The")
- [x] Show in Finder context menu item
- [x] Show in Playlist context menu item
- [x] Album grid view
- [x] Artists view
- [x] Music player
- [x] Support non-Apple digital audio players (directory syncing)
- [x] Sync multiple devices
- [x] Resize cover files
- [x] Preserve track sorting
- [x] Support lyric files (.LRC)
- [x] Lyric file editor
- [x] Support cover files (cover.jpg/cover.png/folder.jpg/folder.png)
- [x] Playlist import/export
- [x] Favorites
- [x] Podcasts (subscribe by RSS feed, download episodes, sync to iPods and audio players)
- [x] Play podcast episodes in the app, resuming where you left off
- [x] Audiobooks (scan a folder of books, sync to iPods and audio players, with a playlist for each book)
- [x] Play audiobooks in the app, file after file, resuming where you left off
- [x] Pick up podcast and audiobook positions from the iPod
- [ ] Mark podcast episodes played from the device's play counts
- [ ] Automatically download new podcast episodes
