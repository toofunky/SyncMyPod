# Features of SyncMyPod

- [x] Support iPod 5G, 5.5G, 6G, 6.5G/7G
- [x] Sync M4A/AAC, M4A/ALAC and MP3 files
- [x] Sync entire library
- [x] Sync partial library (select artist/album)
- [x] Create playlists
- [x] Sync playlists
- [x] Append track artist to title
- [x] Detect meta-data/artwork changes
- [ ] Backup/restore database
- [x] Sync by genre
- [x] Multithreaded library scan
- [x] Light/dark mode
- [x] Tag editor
- [x] Help system
- [x] Eject button
- [x] iTunes-style sorting (ignore "A", "An", and "The")
